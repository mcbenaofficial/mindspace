## Requested Feature

Add a new canvas node type — the **Zen Node** — to `NODE_REGISTRY` under the **Time** category (alongside Pomodoro, Clock, Countdown, Hourglass, World Clock). The node renders a generative, calming audio-visual simulation on a Canvas 2D surface with fully local Web Audio sound synthesis. Six variations ship at launch:

1. **Pendulum Wave** — balls swing on lines from a pivot; chime on wall contact, note by ball index.
2. **Polyrhythm Orbits** — balls travel concentric semicircular arcs at differing speeds, chiming at arc ends.
3. **Rainfall** — drops fall and splash into ripples, each a soft pluck (2.4s decay) over a filtered brown-noise bed.
4. **Breathing Orb** — 4-7-8 guided breathing (box-breathing alternate); detuned sine pad swells with the orb; phase chimes.
5. **Fireflies** — Perlin-drift points with Kuramoto phase coupling; proximity flares trigger soft high bells.
6. **Ocean Swell** — layered translucent sine bands; LFO-driven filtered surf noise, no melodic notes.

Zero assets, zero AI, zero network. All visuals procedural, all audio synthesized at runtime.

Source spec: `v1.8.2-zen-node.md` (attached to the request). This plan reconciles that spec against the current codebase.

## Plan

### 1. Types (`src/types/index.ts`)
- Add `"zen"` to the `NodeType` union.
- Add `ZenVariation`, `ZenScale`, `ZenTone`, `ZenPreset`, and `ZenNodeData` interfaces matching the spec's payload:
  ```ts
  variation, volume(0-1), speed(0.3-1.6), density, scale, rootShift(-1|0|1),
  tone, space(0-0.7), chimeLevel(0-1), ambienceLevel(0-1),
  timerMinutes(number|null), presets(ZenPreset[])
  ```
  Plus a `breathPreset: '478' | 'box'` field (Breathing Orb cycle preset) and `padOn: boolean`, `chimeProbability: number` (Fireflies), `swellPeriod`/`intensity` (Ocean) — folded into the per-variation control set. Playing state is **not** persisted.

### 2. Shared audio singleton (`src/lib/audio/zenAudio.ts`)
New module-level singleton (same pattern as the LM Studio client / `sound.ts`).
- **One shared `AudioContext`** across all Zen Node instances, created lazily on first play gesture, never on import.
- **Voice synth:** per chime one oscillator (type from `tone`) → gain envelope (12ms attack; exp decay 1.8s default, 2.4s rain pluck, ~0.4s kalimba). Fire-and-forget; stop + disconnect after decay.
- **Scale system:** `maj_penta`, `min_penta`, `hirajoshi` expanded across 3 octaves; `rootShift` multiplies all freqs by `2^shift`.
- **Space bus:** master gain → feedback delay (340ms, fb 0.38) → wet gain (the Space control). No convolution reverb (out of scope).
- **Noise beds:** one looped 3s brown-noise buffer through a lowpass (Rainfall static low gain; Ocean LFO-driven gain + cutoff).
- **Pad:** two detuned sines (110 + 110.6Hz) for Breathing Orb, gain via `setTargetAtTime`.
- **Per-node subtree:** each node owns a gain subtree into the shared context; multiple playing nodes mix. Pausing a node ramps its subtree gain to 0 and cancels scheduling; the shared context **suspends only when no Zen Node is playing**.
- **Lookahead scheduler** (Chris Wilson "two clocks" `setInterval` lookahead) so chime timing stays accurate (±30ms) while RAF rendering is paused offscreen.

### 3. Per-variation modules (`src/lib/zen/variations/*.ts`)
One module per variation behind a common interface so variation 7 is a single new file:
```ts
interface ZenVariationModule {
  init(env): State;
  step(dt, ctx2d, env): void;   // advances sim + draws + schedules chimes via audio handle
  dispose(): void;
}
```
Files: `pendulum.ts`, `orbits.ts`, `rain.ts`, `breath.ts`, `fireflies.ts`, `ocean.ts`, plus `index.ts` (registry map) and shared `perlin.ts` helper for Fireflies drift.

### 4. Node component (`src/components/nodes/ZenNode.tsx`)
- Standard node shell (`NodeProps<ZenNodeType>`, `data.mindNode`, `mindNode.data as ZenNodeData`, `updateNode(id,{data})`, `NodeResizer`, delete-on-cmd) consistent with PomodoroNode/CosmicNode.
- **Header:** variation name (14px medium) + variation switcher (segmented/dropdown, 6 entries, instant switch, ~0.5s audio crossfade); session timer chip when active.
- **Canvas body:** Canvas 2D, default 360×400, self-sizing via `ResizeObserver` (CosmicNode's `useResizingCanvas` pattern), RAF loop. **`IntersectionObserver` pauses RAF rendering when offscreen; audio keeps playing** (scheduler is on the audio lookahead, not RAF). Also pause RAF when the tab is inactive.
- **Control strip:** play/pause (the only audio start/stop — satisfies the autoplay gesture requirement), master volume, expandable "tuning" drawer with per-variation controls (speed [hidden on Breathing Orb], density, scale, root note, tone, space, chime level, ambience level [Rainfall/Ocean], breath preset + pad toggle [Breathing], chime probability [Fireflies], swell period + intensity [Ocean], session timer, presets).
- **Session timer:** Off / 10 / 25 / 45 / custom; audio fades out over the final 20s; on reaching zero fires the Automations event (below) and stops.
- **Presets:** save the full settings object under a name; recall in one tap. Stored in `data.presets`.
- **Accessibility:** native input sliders, keyboard reachable; Breathing Orb phase text is an `aria-live` region; honour `prefers-reduced-motion` (default to Ocean Swell at reduced amplitude, disable Fireflies flare; audio unaffected).

### 5. Registry entry (`src/components/nodes/registry.tsx`)
- Import `ZenNode` and `Waves`.
- Add the `zen` entry to `NODE_REGISTRY` under `category: "time"`, `defaultSize: { width: 360, height: 420 }`, with a `ZEN_DEFAULTS` factory (variation `pendulum`, volume 0.55, paused — playing state isn't stored).

### 6. Automations hook (`src/lib/rules/engine.ts` + `src/components/settings/AutomationsSection.tsx`)

- Export `notifyZenSessionCompleted({ nodeId, canvasId, variation, durationMinutes })` — fire-and-forget, mirroring `notifyNodeCreated`; the ZenNode calls it when its timer hits zero. Payload feeds the existing `FireContext` (`title` = variation label).
- Add the trigger to `TRIGGER_KINDS`, `triggerSummary`, and `setTriggerKind` in AutomationsSection (with an optional variation filter). **No new action types** — reuses notify / create-note / etc.

### 7. Version + release
- Bump `package.json` and `src-tauri/tauri.conf.json` to `1.10.0`.

## Technical Overview of the Build
- **Audio (`src/lib/audio/zenAudio.ts`)** — module-level singleton over one shared `AudioContext`, created lazily and never on import (boot beacon confirmed `audioCtxAtBoot: "none"`). `ZenNodeAudio` builds its gain subtree lazily on the first `start()` (the play gesture): dry path + a feedback-delay "space" bus (340ms / 0.38 fb / wet = Space control), an optional looped brown-noise bed (Rainfall/Ocean), and a detuned-sine pad (Breathing Orb). Voices are fire-and-forget oscillator+envelope nodes that self-disconnect after decay. The shared context suspends whenever no node is playing.
- **Variations (`src/lib/zen/variations/*`)** — one file per variation implementing `ZenVariationModule { init, step, dispose, phaseText? }`; `index.ts` maps them and exposes labels/order/melodic flags; `perlin.ts` powers Fireflies drift; `defaults.ts` is the spawn factory. Adding variation #7 is one new file + one line.
- **Component (`ZenNode.tsx`)** — standard node shell (`data.mindNode` / `updateNode`). A single driver loop steps the active variation: a `requestAnimationFrame` loop draws while visible, and a 25ms `setInterval` keeps the simulation/audio scheduling alive while offscreen or when the tab is hidden (so chimes stay accurate without rendering — the criterion-3 path). An `IntersectionObserver` toggles visibility; a `ResizeObserver` keeps the canvas sized. Theme colors are resolved from CSS variables (~2×/sec). The audio handle is created on the play gesture; on first play the active variation is re-initialised so noise/pad start against the live graph.
- **Automations** — new event-style `RuleTrigger` kind `zen-session-completed` (optional variation + canvas filters); `notifyZenSessionCompleted(...)` mirrors `notifyNodeCreated` (fire-and-forget, unique fire-key per session). No new action types — it reuses notify/create-note/etc.
- **Persistence** — `ZenNodeData` rides the existing SQLite node-data path; playing state is deliberately not persisted (nodes load paused).

## Functional Overview of the Build
Spawn **Zen** from the node menu under **Time**. It appears paused showing Pendulum Wave. Pick any of six variations from the header dropdown (instant switch with a ~0.5s audio crossfade). Press play (a real user gesture, required for audio) to begin sound; the visual animates even while paused. Open the tuning drawer (sliders icon) for per-variation controls: speed (hidden on Breathing Orb), density, space, chime level, scale/root/tone (melodic variations), ambience (Rainfall/Ocean), chime chance (Fireflies), cycle + pad (Breathing Orb), swell period + intensity (Ocean Swell). Set a session timer (Off/10/25/45) — audio fades over the final 20s and fires the "Zen session completed" Automation. Save the current setup as a named preset and recall it in one tap. Audio keeps playing when the node scrolls offscreen; rendering pauses to save CPU.
